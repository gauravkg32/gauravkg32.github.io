# Kumar Gaurav — Personal Site

Jekyll site hosted on GitHub Pages at https://gauravkg32.github.io

| Want to change… | Edit |
|---|---|
| Name, tagline, email, social links | `_config.yml` |
| Home page sections | `index.html` |
| Colors / fonts | `assets/css/style.css` (tokens at the top) |
| Blog posts | add `_posts/YYYY-MM-DD-title.md` |

Deploy: push to `main` of repo `gauravkg32.github.io`, then Settings → Pages → Deploy from branch `main` / root.
