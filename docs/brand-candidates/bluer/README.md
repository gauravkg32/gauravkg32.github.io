# Bluer mint, a candidate (23 Nov 2026)

Not adopted. One of Kumar's two favourites, with `../glow/`.

Mint `#3EEBA0` turned 16 degrees toward blue (in OKLCH, at the same lightness), one solid colour with no glow, and the
flame in electric blue.

| | Dark backgrounds | White backgrounds |
|---|---|---|
| Green | `#08EAC4` (was `#4ADE80`) | `#077E69`, 5.0:1 on white (was `#15803D`) |
| Flame | `#3D7BFF` (was `#38BDF8`) | `#3469D9` (was `#0284C7`) |
| Flame core | `#DCE6FF` (was `#E0F2FE`) | `#C9D7FF` (was `#BAE6FD`) |

Being solid, the same colour works for the logo, buttons and links, and in flat print. Made by `_tools/make_logos.py`
with the colours swapped: run `python docs/brand-candidates/bluer/make_bluer.py` from the repo root.
